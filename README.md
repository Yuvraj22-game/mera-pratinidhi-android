# Mera Pratinidhi (Android)

**Mera Pratinidhi** (*"My Representative"*) is a civic-engagement Android application designed to improve transparency and communication between citizens and their elected representatives.

## Key Features
* **Representative Directory:** Look up constituency details, profiles, and contact information for local representatives.
* **Civic Issue Reporting:** Submit local grievances (roads, sanitation, water, electricity) with location tags and photo attachments.
* **Real-Time Status Tracking:** Monitor the progress of submitted complaints from acknowledgment to resolution.
* **Constituency Updates:** View public announcements, development initiatives, and community notices.

## Tech Stack
* **Language:** Kotlin / Java
* **UI:** Jetpack Compose / XML
* **Backend & Auth:** Firebase / REST API
